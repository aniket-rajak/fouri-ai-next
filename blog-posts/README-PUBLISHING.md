## Step 3: Publishing Settings

For each post:
1. **Author Name:** `FOURI Team`
2. **Status:** Select `PUBLISHED` (or `SCHEDULED` if you want a specific date)
3. **Categories:** Select the categories listed above (minimum 1 required)
4. **Excerpt:** Copy the first paragraph (Introduction section) — it makes a great preview
5. **Thumbnail:** Leave blank (will show the "F" placeholder logo)
6. **Tags:** Add the tags listed above for SEO
